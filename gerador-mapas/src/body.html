Como usar a ferramenta

O fluxo completo tem quatro passos. Só é necessário repetir os passos 1 a 3 quando a base ou o modelo Word mudarem.

  1. Base de dados — confira ou substitua a planilha oficial.
  2. Modelos Word — confira ou substitua os arquivos .docx.
  3. Mapeamento — defina qual coluna da planilha alimenta cada campo do documento. Esta tela substitui qualquer alteração de código.
  4. Gerar documentos — informe os códigos e baixe em Word ou PDF.
i
Ao trocar um modelo Word, abra o Mapeamento e clique em Sugerir automaticamente. A ferramenta lê os campos de mesclagem do documento e propõe a coluna correspondente.

Códigos dos cargos

Separe por vírgula, espaço ou quebra de linha.

O Word gera um arquivo por cargo. O PDF reúne todos os mapas em um único documento para impressão.

i
Lógica 1 para 1: cada código gera exatamente um documento, com os dados da própria linha e sempre no modelo individual — mesmo que o cargo pertença a uma trilha JR/PL/SR.

Códigos dos cargos

Aceita um código ou uma lista em massa.

Cada código vira um arquivo Word separado. O PDF reúne os descritivos em páginas distintas.
