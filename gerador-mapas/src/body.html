Como usar a ferramenta

Os passos 1 a 4 só precisam ser repetidos quando a base ou os modelos mudarem.

  1. Base de dados — confira ou substitua a planilha oficial.
  2. Modelos Word — adicione quantos arquivos .docx forem necessários e defina, para cada um, quando ele deve ser usado.
  3. Mapeamento — defina qual coluna da planilha alimenta cada campo de cada modelo.
  4. Salvar e distribuir — gere a ferramenta pronta para enviar a quem vai usar.
  5. Gerar documentos — informe os códigos e baixe em Word ou PDF.
i
Ao adicionar um modelo, a ferramenta lê os campos «CAMPO» do documento e já propõe a coluna correspondente. Só é preciso ajustar o que ela não reconhecer.

Adicionar um modelo

Selecione um arquivo .docx. A estrutura é lida na hora e os campos já vêm mapeados automaticamente quando possível.

i
A ordem importa: ao gerar, cada cargo usa o primeiro modelo cuja regra combinar. Deixe o modelo mais genérico por último, com a regra qualquer cargo.
!
Há alterações não salvas. Elas valem para esta sessão; clique em Salvar mapeamento para mantê-las neste navegador.

Códigos dos cargos

Separe por vírgula, espaço ou quebra de linha.

O Word gera um arquivo por cargo. O PDF reúne todos os mapas em um único documento para impressão.

i
Lógica 1 para 1: cada código gera exatamente um documento, com os dados da própria linha e sempre no modelo escolhido abaixo — independente das regras.

Gerar a ferramenta pronta

Cria um novo arquivo HTML já com os modelos, o mapeamento e as regras configurados. Quem receber só abre e usa — não precisa configurar nada.

Com a base gera um arquivo maior, pronto para usar sozinho. Sem a base gera um arquivo leve; quem abrir seleciona a planilha no próprio computador — indique quando o arquivo for circular por e-mail ou fora da rede interna.
